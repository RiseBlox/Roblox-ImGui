# Roblox-ImGui — Prototype (Discontinued)

> **Archived prototype.** This branch contains the original independent Roblox-native recreation of Dear ImGui's API and appearance. It is incomplete and discontinued in favor of the source-level Dear ImGui port planned on the `main` branch.

This implementation is **not a port of Dear ImGui source code**. It was an independent Luau library using retained Roblox GUI instances, with a subset of ImGui-inspired controls and layout features. It does not aim to achieve full API or behavioral parity.

The code and milestone tests are preserved here for historical reference. No further feature development is planned on this branch.

For the active project direction, see [main](https://github.com/RiseBlox/Roblox-ImGui/tree/main).

## Archived status

- Incomplete, experimental recreation
- Discontinued
- Not intended as the active implementation
- Kept for reference only
